# GCC 5 compatibility sources

`isl-0.10/` and `mpfr-3.1.4/` preserve the previous vendored sources unchanged.
They provide the library ABIs used by Nexmon's bundled GCC 5.4.1 compiler.

The current versions are `../isl-0.28/` and `../mpfr-4.2.2/`. See
[MPFR and ISL](../MATH_LIBRARIES.md) for source provenance, build instructions,
and the distinction between current libraries and compiler compatibility files.
